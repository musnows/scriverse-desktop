# Bundled font licenses

The desktop client bundles the following font software from Fontsource packages.

- Noto Sans SC Variable 5.3.0: `@fontsource-variable/noto-sans-sc`, SIL Open Font License 1.1
- Noto Serif SC Variable 5.3.0: `@fontsource-variable/noto-serif-sc`, SIL Open Font License 1.1
- JetBrains Mono Variable 5.3.0: `@fontsource-variable/jetbrains-mono`, SIL Open Font License 1.1
- Source Code Pro Variable 5.3.0: `@fontsource-variable/source-code-pro`, SIL Open Font License 1.1

The original license text for each font is kept in its corresponding directory.

The bundled TrueType files come from the upstream Noto CJK, JetBrains Mono, and Source Code Pro repositories and remain covered by the same SIL Open Font License 1.1 terms.
